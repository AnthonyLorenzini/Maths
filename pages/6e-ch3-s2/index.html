Placer une fraction sur une demi-droite

Chapitre 3, séance 2

Activité les sauts de puce

Choisis une fraction, puis clique sur « Étape suivante ». La puce part de 0 et fait des sauts égaux.

1. l'unité2. partager3. compter les sauts

1. L'unité, c'est le segment de 0 à 1.

2. Pour placer ab, on partage l'unité en b parts égales : chaque graduation vaut 1b.

3. On compte a sauts à partir de 0. On compte les sauts, pas les traits !

4. Le nombre qui repère un point est son abscisse.

Dans ton cahier : le numéro de l'exercice, la lettre et ta réponse, sans recopier.

Exercice 1 lire une abscisse

L'unité est partagée en 4. Écris l'abscisse de chaque point avec une fraction.

  1. A(?14)
  2. B(?34)
  3. C(?54)
  4. D(?74)

Chaque saut vaut 1/4. C est à 5 sauts de 0 : 5/4 (c'est après 1, donc plus grand que 1).

Exercice 2 quelle lettre ?

Les fractions sont déjà placées. Écris la lettre du point qui correspond à chaque fraction.

  1. 23 → ?H
  2. 53 → ?G
  3. 13 → ?F
  4. 43 → ?E

L'unité est coupée en 3 : on compte les sauts de 1/3 depuis 0.

Exercice 3 qui a raison ?

Lis la droite, puis écris le prénom de l'élève qui a raison.

Sami : « Je compte les traits de 0 jusqu'à P : il y en a 4. Donc P(4/5). »Lina : « Je compte les sauts depuis 0 : 1, 2, 3. Donc P(3/5). »

Qui a raison ? ?Lina

Lina. Sami a compté aussi le trait de 0 : il faut compter les sauts, pas les traits. P est à 3 sauts de 1/5.

Exercice 4 la droite ne commence pas à 0

Attention : cette demi-droite commence à 1. L'unité est partagée en 5. Écris l'abscisse de R et de S.

  1. R(?75)
  2. S(?95)

On ne part pas de 0 ! 1 = 5/5. R est 2 sauts après 1 : 5 + 2 = 7, donc 7/5. S : 5 + 4 = 9, donc 9/5.
